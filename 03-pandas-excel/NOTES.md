# 03. pandas & Excel — Module Overview & Index

This skill covers practical data processing for structured business data using pandas (data manipulation) and openpyxl (Excel workbook generation). The goal is to go from a messy CSV file to a validated, transformed, formatted Excel report — the full data-processing pipeline a junior data or backend engineer encounters in real work.

---

## Curriculum Index & Subsection Overviews

1. [**3.1 DataFrames**](exercises/3.1-dataframes/NOTES.md)
   Loading CSVs, inspecting dtypes, shape, head/tail, boolean indexing, null counts, and a reusable data-quality report function.

2. [**3.2 Cleaning**](exercises/3.2-cleaning/NOTES.md)
   Removing duplicates, normalizing date formats, fixing inconsistent casing, filling missing values, type conversion — every decision documented in `ASSUMPTIONS.md`.

3. [**3.3 Transformations**](exercises/3.3-transformations/NOTES.md)
   `groupby` + `agg` for monthly summaries, `merge` for joining a reference table, `pivot_table` for cross-tabulations, and adding calculated columns.

4. [**3.4 Excel Workbooks**](exercises/3.4-excel-workbooks/NOTES.md)
   Writing multi-sheet `.xlsx` files with openpyxl — styled header rows, freeze panes, currency formatting, and auto-fitted column widths.

5. [**3.5 Validation**](exercises/3.5-validation/NOTES.md)
   Schema-driven validation returning structured error objects — required columns, dtype checks, value ranges, primary key uniqueness, and allowed-values enforcement.

6. [**3.6 Performance**](exercises/3.6-performance/NOTES.md)
   Side-by-side comparison of a Python for-loop vs vectorized `np.select` on 100k rows, with timing and a plain-English explanation of why vectorization wins.

- [**Independent Project: Excel Report Pipeline**](independent/excel_report_pipeline/README.md)
  An end-to-end pipeline wiring validation → cleaning → transformation → Excel output, with an error-summary sheet listing any rows that failed validation.
