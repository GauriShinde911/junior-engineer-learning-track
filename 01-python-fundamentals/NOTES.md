# 01. Python Fundamentals — Module Overview & Index

Building software engineering ability requires mastery over core language semantics before adopting web frameworks or ORMs. This module covers foundational Python mechanics: execution lifecycles, control flow branching, collection data structures, pure functions, safe file handling, exception hierarchies, and the standard library.

---

## Curriculum Index & Subsection Overviews

1. [**1.1 Syntax & Execution**](exercises/1.1-syntax-execution/NOTES.md)
   Variables, primitive types, arithmetic operators, console I/O, script execution guards, and handling invalid user input.

2. [**1.2 Control Flow**](exercises/1.2-control-flow/NOTES.md)
   Conditional branching (`if`/`elif`/`else`), loop constructs (`for`, `while`), `range()`, nested iterations, and early loop termination (`break`, `continue`).

3. [**1.3 Collections**](exercises/1.3-collections/NOTES.md)
   Lists, tuples, sets, dictionaries, comprehensions, composite tuple keys, and memory aliasing versus shallow/deep copying.

4. [**1.4 Functions**](exercises/1.4-functions/NOTES.md)
   Parameters, return semantics, default values, keyword-only constraints, `*args`, `**kwargs`, LEGB scope rules, and pure function architecture.

5. [**1.5 Strings & Files**](exercises/1.5-strings-files/NOTES.md)
   String slicing and formatting, `pathlib.Path` operations, character encodings (`utf-8`), and non-crashing file processing.

6. [**1.6 Exceptions**](exercises/1.6-exceptions/NOTES.md)
   `try`/`except`/`else`/`finally` lifecycle, custom exception hierarchies, and distinguishing expected user validation errors from system defects.

7. [**1.7 Standard Library**](exercises/1.7-standard-library/NOTES.md)
   Batteries-included tools: `datetime` calendar arithmetic, `json` and `csv` serialization, `re` regular expressions, and `collections.Counter`.
