# Capstone Project: Asset Request & Tracking App

Final project combining all 12 core engineering skills into a production-grade, end-to-end application.

---

## Project Structure

```
capstone-asset-tracker/
├── src/                <- Application source code
├── tests/              <- Unit and integration tests (pytest)
├── docs/               <- Technical documentation, architecture diagrams, user guides
└── README.md           <- Project overview, setup, and usage instructions
```

---

## Skills Integrated

- **Python & OOP Design**: Modular architecture and clean class hierarchies.
- **SQLite Database**: Persistent data store for asset inventory, requests, and audit logs.
- **Pandas**: Inventory analytics, status reports, and Excel export functionality.
- **REST API / Auth**: Secure access controls and API endpoints.
- **Streamlit**: Interactive user dashboard for submitting, approving, and tracking asset requests.
- **Logging & Error Handling**: Comprehensive logging for all operational events.
- **Testing**: Automated test suite with pytest.
- **Packaging & Docs**: Standalone executable build and end-to-end documentation.

---

## Running the Capstone

```bash
# Run the test suite
pytest capstone-asset-tracker/tests/
```
